3차원 성적서 변환

3차원 측정기(CMM) 결과 파일을 회사 성적서 엑셀 양식에 자동으로 채워 넣습니다. 파일은 브라우저 안에서만 처리되고 어디에도 업로드되지 않습니다.

1성적서 양식 엑셀 (.xlsx)

양식 파일을 끌어다 놓거나 클릭해서 선택

    아래 설정 칸(주황색으로 표시되는 칸)을 클릭한 뒤 양식 미리보기의 셀을 누르면 위치가 자동으로 들어갑니다.

    23차원 측정 결과 파일

    측정 결과 파일을 끌어다 놓거나 클릭해서 선택 (xlsx · xls · csv · txt, 여러 개 = 시료 1, 2, 3…)

      PC-DMIS·Calypso 등에서 내보낸 표 형식(엑셀/CSV/텍스트)을 읽습니다. 제목 행은 자동으로 찾으며, 틀리면 직접 번호를 고치면 됩니다.

      3어디에 넣을지 지정

      각 항목마다 측정 파일의 어떤 열을 양식의 어떤 열에 넣을지 고릅니다. 양식 열을 비워두면 그 항목은 넣지 않습니다.

      판정

      머리글 칸 (품명, 품번, 날짜 등)

      설정 저장

      설정은 이 브라우저에 저장됩니다. 한 번 맞춰두면 다음부터는 파일만 올리고 바로 변환하면 됩니다.
